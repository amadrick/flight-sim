# Skyward Flight Simulator

A flight simulator that ships as one self-contained HTML file (a claude.ai Artifact): three.js + WebGL2,
with every aircraft, texture, cloud and sound generated by code. Nothing is loaded from the network at runtime.

- `ARCHITECTURE.md` is the contract every module follows (coordinates, shared context, data shapes, events,
  rendering and lighting rules, controls, aircraft roster).
- One module per directory under `src/`: `physics`, `render`, `clouds`, `terrain`, `water`, `scenery`,
  `aircraft` (modelling kit plus one folder per aircraft), `effects`, `camera`, `input`, `audio`, `ui/hud`,
  `ui/menu`, `neural`. `src/core` and `src/main.js` tie them together.

## Build

```
npm install
node tools/build.mjs        # writes dist/index.html, the single file that is published as the artifact
npm test                    # unit tests
node tools/shot.mjs --params "aircraft=f16&start=air" --out shots/f16.png   # headless screenshot + smoke test
```
